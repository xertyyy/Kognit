## 🚀 In 3 Schritten loslegen

| | |
|:-:|---|
| **1** | **Link öffnen:** Tippe oben auf **„App öffnen“**, am Handy oder am Computer. |
| **2** | **Anmelden:** mit Google oder E-Mail, oder einfach **„Als Gast fortfahren“**. |
| **3** | **Tour mitmachen:** Eine kurze Tour zeigt dir, wo alles ist. |

## ✨ Was Kognit kann

| | Bereich | Was du da machst |
|:-:|---|---|
| 📖 | **Wissen** | Lernseiten zu jedem Thema. Nicht verstanden? Tippe auf **„Erklär’s mir anders“**. |
| ⚡ | **Quiz** | Runden mit je **5 Fragen**, mit **Tipps**, wenn du nicht weiterkommst. |
| 🎓 | **Prüfung** | Eine Probeklausur mit **Note**, wenn du dich bereit fühlst. |
| ⏱️ | **Timer** | Lernen in Etappen mit Pausen. |
| 📄 | **Eigener Stoff** | Eine kostenlose KI wie ChatGPT baut aus deinen Unterlagen Lernseiten und Fragen. Die Anleitung steht in der App. |
| 👤 | **Profil** | Konto, Lernstand herunter- und hochladen, Anleitung und Tour. |

> [!TIP]
> **Am besten so lernen:** erst die Lernseiten lesen, dann im Quiz üben und zum Schluss die Probeprüfung schreiben.

## 💾 Wird mein Fortschritt gespeichert?

| | |
|---|---|
| ✅ **Mit Konto** | Alles wird gespeichert und ist auf jedem Gerät da. |
| ⚠️ **Als Gast** | Es wird nichts gespeichert. Beim Neuladen ist alles weg. |
| 📁 **Lernstand als Datei** | Im **Profil** kannst du ihn herunterladen und auf einem anderen Gerät wieder hochladen. |

> [!IMPORTANT]
> Willst du deinen Fortschritt behalten, **melde dich an**. Als Gast ist alles weg, sobald du die Seite neu lädst.

## 📱 Kognit wie eine App aufs Handy

<details>
<summary><b>iPhone (Safari)</b></summary>
<br>

1. Öffne den Link in **Safari**.
2. Tippe unten auf **Teilen** (Quadrat mit Pfeil).
3. Wähle **„Zum Home-Bildschirm“** und tippe auf **„Hinzufügen“**.

Öffne Kognit ab dann nur noch über das neue Symbol.

</details>

<details>
<summary><b>Android (Chrome)</b></summary>
<br>

1. Öffne den Link in **Chrome**.
2. Tippe oben rechts auf die **drei Punkte**.
3. Wähle **„Zum Startbildschirm hinzufügen“**.

</details>

## 🔒 Datenschutz

> [!NOTE]
> Wenn du dich anmeldest, werden deine **E-Mail-Adresse** und dein **Lernstand** bei **Google Firebase** gespeichert. Andere Nutzer sehen deine Daten nicht. Lade beim eigenen Lernstoff keine privaten Daten in die KI hoch.
